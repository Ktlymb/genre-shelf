# Genre Shelf 工程规格书

> 版本：v0.1（草案）　状态：待委托人确认
> 一个记录「读过的书」的多用户网站：世界地图直观展示阅读分布，Notion 式表格做筛选与分析。

---

## 1. 目标与范围

### 1.1 目标

1. 用户注册登录后，录入自己读过的书。
2. **地图页**：世界地图按各国已读书数量着色；悬停国家查看作者与作品；点击书名进入详情。
3. **表格页**：以表格展示全部书籍，支持筛选、排序、分组、汇总与图表分析。
4. 可以分享给书友：每人独立书库，可选择公开自己的页面。

### 1.2 第一版（v1）不做

- 书友之间的关注、评论、点赞等社交功能
- 自动抓取书籍信息（豆瓣、ISBN 查询等）
- 多语言界面（只做中文，但文案集中存放，为以后加英文留口子）
- 原生手机 App（网页做好手机适配即可）
- 历史国家的"合并色块"显示（见 §5.5，列入 v2）

## 3. 技术选型

选型原则：**免费额度够用、部署简单、数据可随时迁走**。

| 层 | 选择 | 理由 |
|---|---|---|
| 前端框架 | Next.js（App Router）+ TypeScript | 生态成熟，一个项目同时包含页面和服务端逻辑 |
| 样式 | Tailwind CSS | 开发快，手机适配方便 |
| 数据库 | PostgreSQL | 标准数据库，不绑定厂商 |
| 登录与权限 | Supabase Auth + Row Level Security（行级安全） | 邮箱密码登录、找回密码开箱即用；权限在数据库层强制，不会因前端疏漏泄露他人数据 |
| 托管 | Vercel（网站）+ Supabase（数据库），均用免费套餐起步 | 无需自己维护服务器 |
| 地图 | D3-geo + d3-zoom 渲染 SVG；底图用 Natural Earth 1:50m（公有领域） | 着色、缩放、悬停完全可控 |
| 表格 | TanStack Table（无样式表格引擎）+ 自建筛选/分组/汇总层 | 要做到类 Notion 的体验，现成「大而全」的表格组件反而难改 |
| 图表 | Recharts | 够用，与 React 配合好 |
| 色彩插值 | culori（OKLab 空间插值） | 蓝→红直接按 RGB 插值会出现脏紫色，OKLab 过渡更干净 |
| 测试 | Vitest（单元）+ Playwright（端到端） | |

**已知风险**：Vercel / Supabase 的默认域名在中国大陆部分网络下访问较慢或不稳定。若书友主要在大陆，需要绑定自有域名并评估；或改用「Docker 自托管（Next.js + PostgreSQL）」。因为数据库是标准 PostgreSQL，迁移成本可控（见 §14）。

## 4. 数据模型

### 4.1 实体关系

```
profiles 1──* books *──* authors            （books 与 authors 经 book_authors 关联）
                │ *──1 book_types
                │ *──1 countries
profiles 1──* authors
profiles 1──* saved_views
countries（预设数据，所有人共享；含现代国家与历史国家）
book_types（预设 + 用户自定义）
```

### 4.2 表结构

```sql
-- 用户资料（与 Supabase auth.users 一对一）
create table profiles (
  id            uuid primary key references auth.users on delete cascade,
  display_name  text not null,
  slug          text unique,                 -- 公开页地址 /u/<slug>
  is_public     boolean not null default false,
  settings      jsonb not null default '{}', -- 地图两极颜色、着色依据、映射模式等
  created_at    timestamptz not null default now()
);

-- 国家/地区（含历史国家）
create table countries (
  code        text primary key,              -- 现代国家用 ISO 3166-1 alpha-2，如 GR；历史国家用自定义码，如 SU、YU
  name_zh     text not null,
  name_en     text not null,
  kind        text not null check (kind in ('modern','historical')),
  valid_from  int,                           -- 历史国家的存续年份
  valid_to    int,
  map_codes   text[] not null,               -- 对应地图上的哪些现代色块；现代国家就是它自己
  sort_order  int not null default 0
);

-- 书籍类型（user_id 为空 = 系统预设，所有人可见；非空 = 用户自定义）
create table book_types (
  id          bigint generated always as identity primary key,
  user_id     uuid references profiles on delete cascade,
  code        text not null check (code ~ '^[A-Z]{4}$'),   -- 图标上的四字母简称
  name_zh     text not null,
  bg_color    text not null check (bg_color ~ '^#[0-9A-Fa-f]{6}$'),
  sort_order  int not null default 0,
  unique (user_id, code)
);

-- 作者（每个用户自己一份，避免互相污染）
create table authors (
  id            bigint generated always as identity primary key,
  user_id       uuid not null references profiles on delete cascade,
  name          text not null,
  name_original text,
  country_code  text references countries,   -- 作者国籍，用于录书时的默认值
  unique (user_id, name)
);

-- 书籍
create table books (
  id            bigint generated always as identity primary key,  -- 书籍编号（主键）
  user_id       uuid not null references profiles on delete cascade,
  title         text not null,               -- 书名
  original_title text,                       -- 原著名
  country_code  text not null references countries,  -- 地图归属国
  type_id       bigint not null references book_types,
  word_count    int check (word_count >= 0), -- 字数，可空
  year_written  int,                         -- 创作年份，可为负数（公元前）
  year_approx   boolean not null default false,       -- 「约」
  translators   text[] not null default '{}',
  publisher     text,
  finished_on   date,                        -- 读完日期；空 = 未读完/日期不详
  status        text not null default 'finished' check (status in ('reading','finished')),
  rating        smallint check (rating between 1 and 5),
  isbn          text,
  notes         text,                        -- 读后感/笔记
  created_at    timestamptz not null default now(),
  updated_at    timestamptz not null default now()
);

-- 书-作者关联（有序，第一位为第一作者）
create table book_authors (
  book_id    bigint references books on delete cascade,
  author_id  bigint references authors on delete restrict,
  position   smallint not null default 0,
  primary key (book_id, author_id)
);

-- 表格视图（保存筛选/排序/分组/列显示配置）
create table saved_views (
  id        bigint generated always as identity primary key,
  user_id   uuid not null references profiles on delete cascade,
  name      text not null,
  config    jsonb not null,
  position  int not null default 0
);
```

**索引**：`books(user_id, country_code)`、`books(user_id, finished_on)`、`book_authors(author_id)`。

### 4.3 字段对照（对应原始需求）

| 原始字段 | 数据库字段 | 类型 | 必填 |
|---|---|---|---|
| 书籍编号（主键） | `books.id` | 自增整数 | 自动 |
| （补充）书名 | `title` | 文本 | 是 |
| 作者 | `book_authors` → `authors` | 多对多 | 是，至少一位 |
| 国家 | `country_code` | 外键 | 是（默认取第一作者国籍） |
| 字数 | `word_count` | 整数 | 否 |
| 书籍类型 | `type_id` | 外键（单选） | 是 |
| 创作年份 | `year_written` + `year_approx` | 整数 + 布尔 | 否 |
| 译者 | `translators` | 文本数组 | 否 |
| 出版社 | `publisher` | 文本 | 否 |
| 读完日期 | `finished_on` | 日期 | 否 |
| 原著名 | `original_title` | 文本 | 否 |
| （补充）评分、笔记、ISBN、状态 | `rating`、`notes`、`isbn`、`status` | | 否 |

### 4.5 历史国家（回应委托人补充）

**问题**：用户读过「南斯拉夫联盟」的书，但地图上没有这个国家的色块。

**做法**：`countries` 表里同时存放现代国家与历史国家。每本书的 `country_code` 记录**历史上真实的归属**（不改写史实），`map_codes` 字段说明它在今天的地图上对应哪些色块。

| `YUS` | 南斯拉夫社会主义联邦共和国 | 1945–1992 | SI、HR、BA、RS、ME、XK、MK |
| `CSK` | 塞尔维亚和黑山 | 2003–2006 | RS、ME、XK |
| `SU` | 苏联 | 1922–1991 | RU、UA、BY、MD、LT、LV、EE、GE、AM、AZ、KZ、UZ、TM、KG、TJ |
| `CS` | 捷克斯洛伐克 | 1918–1992 | CZ、SK |
| `DDR` | 东德 | 1949–1990 | DE |
| `FRG` | 西德 | 1949–1990 | DE |

## 5. 地图页

### 5.1 渲染

- 底图：Natural Earth 1:50m admin-0，构建脚本 `scripts/build-map.ts` 转为简化的 TopoJSON，每个多边形带统一的 `code` 属性（ISO alpha-2；科索沃为 `XK`）。
- 构建时有一致性检查：`countries` 表里每个现代国家都有对应色块；每个色块都有对应的 `countries` 条目。缺一即报错。
- 投影：Natural Earth 投影，初始视图为全世界。
- 缩放：滚轮 / 双指缩放，范围 1×–40×，可拖动；右下角有「＋ − 复位」按钮；缩放时描边线宽反向补偿，保持视觉粗细不变。
- **微型国家**：面积过小、在地图上看不见的国家和地区（新加坡、马耳他、梵蒂冈、摩纳哥、列支敦士登、圣马力诺、安道尔、马尔代夫、各小岛国等）以**小圆点标记**叠加显示，同样着色、可悬停、可点击。放大到一定倍数后圆点隐去，改显真实边界。
- 无书的国家：中性灰 `#E4E4E4`。

### 5.2 着色算法（解决极端值问题）

要求：一个国家读了 50 本、其余都是几本时，其余国家之间仍要有明显色差。

**默认模式：等级映射（rank mapping）**

```
输入：各国家的书数 n_i（仅统计 n_i > 0 的国家/色块）
1. 取所有不同的数值，升序排列：v_1 < v_2 < … < v_k
2. 若 k == 1：所有国家 t = 0.5
   否则，数值 v_j 的 t = (j - 1) / (k - 1)        // 最少 → 0（纯蓝），最多 → 1（纯红）
3. 颜色 = 在 OKLab 空间里，对 [低端色, 高端色] 按 t 插值
```

例：数值为 {1, 2, 3, 5, 50} → t 依次为 0、0.25、0.5、0.75、1。50 本只占最红的一档，不会把其他国家压成同一种颜色。相同本数的国家颜色相同。

**可选模式**（用户在地图页的设置里切换）：

| 模式 | 公式 | 适用 |
|---|---|---|
| 等级映射（默认） | 如上 | 分布极不均匀 |
| 对数 | `t = log(n) / log(max)` | 想让颜色仍大致反映数量比例 |
| 线性 | `t = (n - min) / (max - min)` | 数据均匀时；极端值下会失效，因此作为选项而非默认 |

**颜色设置**：
- 低端色默认蓝 `#3B6FB6`，高端色默认红 `#C8372D`，两者用户都可改。
- 可选「中间过渡色」（默认关闭；开启后做三色渐变，如蓝 → 浅灰 → 红）。
- 设置保存在 `profiles.settings`，下次打开保持。

**图例**：地图角落显示色带；色带上标出各档对应的本数（等级映射下是「几本 ↔ 哪种颜色」的离散色块，而不是连续刻度）。

### 5.3 悬停面板

**交互设计**（这里与"鼠标悬停"原始描述略有调整，原因见下）：

- 桌面端：鼠标悬停国家约 150ms 后，在右侧（窄屏在底部）弹出面板。鼠标可以移入面板，面板不会消失；点击国家则**固定**面板，再点空白处取消固定。
- 手机/平板：没有悬停，**点按**国家即固定显示面板。
- 调整原因：如果面板只跟随鼠标出现，鼠标一移开就消失，用户就没法点击里面的书名或折叠作者了。

**面板内容**（竖向列表）：

```
🇬🇷 希腊 · 已读 7 本 · 4 位作者
▾ 荷马 (3)
    [EPIC] 奥德赛
    [EPIC] 伊利亚特
    [HIST] ……
▸ 索福克勒斯 (2)
▸ ……
```

- 作者可折叠，默认展开前 3 位，其余收起；顶部提供「全部展开 / 全部折叠」。
- 作者按**该国已读书数**降序；同数量时按作者名排序。作者下的书按读完日期倒序。
- 一本书有多位作者时，在每位作者名下都出现（面板头部的总数按书去重）。
- 书名左侧是类型图标：圆角矩形、该类型背景色、白色四字母简称（如 `EPIC`，棕底）。
- 点击书名 → 书籍详情页 `/books/:id`。
- 历史国家的书，在书名后附小标签，如「南斯拉夫联盟」。
- 书很多的国家：面板内部滚动，最大高度不超过视口。

### 5.4 国家选择

- 悬停/点按时，该国家高亮描边。
- 页面顶部提供「搜索国家」输入框（中文名/英文名），选中后地图自动缩放定位到该国——这是小国难以点中时的备用入口。

### 5.5 历史国家在地图上的规则（v1）

采用**领土归属计数**：

- 一本书归属历史国家时，它计入该条目 `map_codes` 里**每一个**现代色块。
- 每个色块的数量 = 归属到任何覆盖它的条目的书的**去重总数**。
- 悬停面板里，该色块下的书按作者分组，来自历史国家的书带上历史国家标签。

示例：用户读了 4 本南联盟的书、2 本塞尔维亚的书。塞尔维亚色块显示 6 本；黑山与科索沃色块各显示 4 本。

**已知局限**：用 3 个色块各显示 4 本，会让人以为黑山单独读了 4 本。v2 可增加「历史国家合并显示」开关：把覆盖区域并成一个色块，用单一颜色，名称显示为「南斯拉夫联盟（今塞尔维亚、黑山、科索沃）」。v1 先不做。

### 5.6 争议领土

底图的边界与国家归属采用 Natural Earth 的默认处理。台湾、科索沃、克里米亚、西撒哈拉、克什米尔等地区的显示方式属于需要委托人拍板的事项（见 §14）。技术上，每个色块都映射到 `countries` 表，因此**名称与归属可通过数据修改，不需要改代码**。

## 6. 书籍录入与详情页

### 6.1 详情页 `/books/:id`

- 显示书的全部字段：类型图标、书名、原著名、作者（可点击→按该作者筛选的表格）、国家、字数、创作年份（`year_approx` 显示为「约」，负数显示为「公元前」）、译者、出版社、读完日期、评分、ISBN、笔记。
- 笔记支持换行与基础 Markdown。
- 所有者可见「编辑 / 删除」；删除前有确认。
- 顶部有「返回地图」「返回表格」入口，并保持来源状态（比如从哪个国家的面板点进来，返回时回到该国家的视图）。

### 6.2 录入表单

- 作者：输入时自动补全该用户已有作者；没有则「新建作者」，并填国籍。
- 国家：选定作者后**自动带出**第一作者国籍，可手动改；下拉里现代国家与历史国家分组显示，可输入中文名搜索。
- 书籍类型：下拉，每项带彩色图标。
- 创作年份：数字输入，允许负数；旁边是「约」复选框。
- 必填项校验：书名、作者、国家、类型。
- 保存后可选择「继续添加下一本」。

## 7. 表格页（类 Notion）

页面 `/table`，数据与地图页同源。

### 7.1 视图能力

| 能力 | 规格 |
|---|---|
| 列显示 | 每列可显示/隐藏、拖动调整顺序和宽度 |
| 排序 | 多列排序，可拖动调整优先级 |
| 筛选 | 条件构建器：「字段 + 运算符 + 值」，多条件之间支持「且 / 或」。运算符按字段类型提供：文本（包含、等于、为空…）、数字（>、<、介于…）、日期（早于、晚于、本年、最近 N 天…）、选择类（是、不是、任一）|
| 分组 | 按任一字段分组（类型、国家、作者、读完年份、读完月份…），分组可折叠，组头显示该组的汇总 |
| 汇总行 | 每列底部可选聚合方式：计数、非空计数、去重计数、求和、平均、最小、最大、中位数 |
| 搜索 | 顶部关键词搜索（书名、原著名、作者、译者、出版社、笔记） |
| 已保存视图 | 将当前配置（列、排序、筛选、分组、汇总）存为命名视图，顶部标签页切换 |
| 行内编辑 | 单元格双击即可编辑；类型/国家为下拉 |
| 导入导出 | 导出当前视图为 CSV；导入见 §7.3 |

数据量预期：单用户最多几千行。v1 在浏览器端完成全部筛选/排序/分组，不做服务端分页。

### 7.2 数据分析面板 `/table/analysis`

图表均响应当前筛选条件：

1. 每年读书数量（按读完日期）
2. 每年阅读字数；累计字数折线
3. 各类型占比
4. 各国家/地区 Top 20
5. 作者 Top 20（按本数）
6. 作品创作年代分布（按世纪分桶）
7. 评分分布
8. 摘要卡片：总书数、总字数、涉及国家数、涉及作者数、平均每本字数、最长/最短书

### 7.3 CSV 导入导出

- 表头使用中文，与 §4.3 字段名一致：`书名, 原著名, 作者, 国家, 字数, 书籍类型, 创作年份, 译者, 出版社, 读完日期`（可选：`评分, ISBN, 笔记`）。
- 多位作者/译者用 `;` 分隔。
- 国家按中文名匹配 `countries`；类型按名称或简称匹配。
- 导入先做**预览与校验**：显示每行的识别结果，错误行（国家无法识别、日期格式错误等）高亮并说明原因；用户确认后才写入。
- 不存在的作者自动新建；已存在则复用。
- 文件编码兼容 UTF-8（含 BOM，即 Excel 另存的 CSV）。大小上限 2 MB。

## 8. 用户、权限与分享

### 8.1 账号

- 邮箱 + 密码注册，邮箱验证，忘记密码（邮件重置）。
- 注册时设置显示名称。
- 开放注册可通过环境变量 `REQUIRE_INVITE_CODE=true` 切换为凭邀请码注册（A2）。

### 8.2 权限（由数据库 RLS 强制执行）

| 数据 | 所有者 | 其他登录用户 | 未登录访客 |
|---|---|---|---|
| 自己的 books / authors / saved_views | 读写 | 无 | 无 |
| 公开用户（`is_public = true`）的 books / authors | 读写 | 只读 | 只读 |
| `countries`、系统预设 `book_types` | 只读 | 只读 | 只读 |
| 用户自定义 `book_types` | 读写 | 无 | 无（公开页会读取，随公开用户一同只读开放） |

- 管理员（`profiles.is_admin`，手工设置）可维护 `countries`。

### 8.3 公开分享

- 设置页可开启「公开我的书库」，并设置个性化地址 `/u/<slug>`。
- 公开页展示该用户的**地图页和表格页（只读）**，没有编辑入口；不显示邮箱，不显示 `notes`（笔记默认私密，可在设置里选择是否公开笔记）。
- 关闭公开后，该地址立即 404。
- 公开页的着色和颜色设置沿用所有者的设置。

## 13. 验收要点

1. 录入读过的书后，对应国家在地图上变色，且颜色随数量按 §5.2 规则变化。
2. 构造测试数据：一个国家 50 本，其余国家 1、2、3、4 本。后者之间在地图上颜色肉眼可分。
3. 悬停（桌面）或点按（手机）国家，面板列出作者与书；作者可折叠；顺序按本数降序；类型图标颜色与简称正确；点击书名进入详情页。
4. 地图可缩放到能点中卢森堡、新加坡、梵蒂冈等小国。
5. 录入一本归属「南斯拉夫联盟」的书，塞尔维亚、黑山、科索沃均出现颜色；苏联在无书时没有任何色块被着色。
6. 表格可按任意字段筛选/排序/分组，汇总行正确；保存的视图刷新后仍在。
7. 用户 A 无法通过任何路径（页面、接口）读取用户 B 未公开的数据。
8. 导入 100 行 CSV，错误行被指出，确认后正确写入。

## 14. 风险与待确认事项

| # | 事项 | 影响 | 当前处理 |
|---|---|---|---|
| Q1 | 「南斯拉夫联盟」指 1992–2003 的南联盟，还是铁托时代的南斯拉夫？ | 决定着色范围 | 两个都预设，用户录书时选 |
| Q2 | 历史国家在地图上采用「领土归属计数」（§5.5）是否可接受？ | 影响数字的直观性 | v1 按此实现，v2 可增加合并显示 |
| Q3 | 争议领土（台湾、科索沃、克里米亚、西撒哈拉等）如何命名与着色 | 政治敏感，需委托人决定 | 以数据可配置的方式实现，默认按 Natural Earth |
| Q4 | 书友主要在中国大陆吗？ | 影响托管选择（Vercel/Supabase 访问稳定性） | v1 先上这套；如访问不佳，迁移到自托管 |
| Q5 | 开放注册还是邀请码？ | 防止被陌生人刷号 | 默认开放，可一键改为邀请码 |
| Q6 | 一本书只归属一个国家是否足够？（例如流亡作家、跨国合著） | 地图计数口径 | v1 一书一国；可手动覆盖默认值 |
| Q7 | 默认国家取「第一作者国籍」是否合适？ | 录入便利度 | 可手动改 |
| R1 | 免费套餐额度变动或服务停用 | 网站可用性 | 数据为标准 PostgreSQL，可导出迁移；提供全量 CSV 导出 |
| R2 | 表格功能被期望做成「完整 Notion」 | 范围蔓延 | v1 严格限定为 §7 列出的能力 |
